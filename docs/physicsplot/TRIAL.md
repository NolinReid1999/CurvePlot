# PhysicsPlot 0.2 开发试用说明

本版重点是连续大表和基础编辑，以及数据到曲线的初步闭环。它仍是开发试用版，不代表规格书所有 P0 功能已经完成。

## 数据与表格

将 CSV/TXT/TSV 拖到窗口或使用右侧“导入数据”。多个文件会逐一显示导入设置并建立不同工作表。预览可调整编码、分隔符、表头和跳过行/尾注，最多显示前 200 行。完整数据在后台读取，不强制分页。

纯数字首行默认作为数据。非数字内容在预览中保留，导入后的数值表以缺失值表示，并在状态栏和列备注中提示数量与原文件记录示例；不覆盖原 CSV。

直接输入或双击/F2 编辑。Enter 向下、Shift+Enter 向上，Tab/Shift+Tab 横移，Esc 取消编辑。⌘C/⌘X/⌘V、⌘Z/⇧⌘Z 用于复制、剪切、粘贴、撤销和重做。右键行号或列名进行插入、删除；列属性包含角色、单位、备注和稳定 ID。

大块复制/粘贴在后台准备。解析期间若表格已变化，过期粘贴结果会被丢弃，避免覆盖新编辑。撤销历史预算约 128MB，最多 1,000 条；超过单次操作预算时不修改数据，历史释放时显示提示。图形引用的列不能被删除或通过撤销静默移除。

## 绘图与样式

选中 X 和一列/多列 Y，点击“绘图”。多列 Y 会建立独立曲线对象和叠加图。只有一列的数据会新增行号列作为 X，原始列不变；可通过列角色指定 X/Y/XErr/YErr。负误差会被拒绝。

右侧统一为“图形｜拟合｜处理｜导出”。属性区可拖动调整宽度，也可在“视图”菜单中隐藏。图形页提供散点/折线/线点、颜色、线宽/线型、点大小、字号/字体、坐标轴和图例；PNG/SVG/PDF 移至“导出”。单曲线可选择透明背景导出；叠加图的颜色与图例在图形页“曲线与图例”调整。

修改源数据会合并刷新曲线，已有拟合立即标为失效。完整选点/框选、对数坐标、误差端帽设置及分析插件等仍需后续开发，不能按完整 Origin 替代品验收。

## 工程与试用

使用工程文件保存工作表、列属性、图形映射和样式。工程与 CSV 分离；保存通过临时文件原子替换，加载失败保留原工作表和撤销历史。新工程格式包含额外元数据，旧版应用不保证读取，因此旧版安装与更新前工程备份分别保留。

“帮助 → 打开合成示例”可查看现有线性拟合流程。原始真实仪器 CSV 的最终兼容性、复杂字体、完整大数据绘图与拟合仍需按验收清单检查。每版试用请以应用标题中的版本为准。

表格辅助功能当前提供数据规模、当前原始单元格和值、选区数量及键盘访问；尚未提供逐格屏幕阅读器导航。0.2.0-alpha.3 已将工程保存改为后台执行；打开工程仍同步，后续继续处理。

## 0.2.0-alpha.3 新功能

- 保存工程在后台完成，可取消；期间可以继续编辑。保存的是开始时的快照，有新修改时标题保留未保存标记。保存失败、取消或有新修改时，关闭/新建/打开不会继续丢弃当前工作。
- 表格右侧新增“导出表格 CSV…”，后台写入并可取消；先写临时文件再替换，保留已有文件直到成功完成。
- 右键行号/列头可“生成等差序列到新列…”，填写起始值和步长；支持负/零步长、科学计数法，结果可撤销重做。原列保持不变。
- 单曲线“图形”页新增“选点与 X 区间”：开启点击选点后，点击曲线附近显示真实源行号、X/Y 和已配置误差；“定位到源工作表”跳到原行。无附近数据时不显示虚构插值点。源数据变化会清除旧选点。
- “拖动 X 区间用于拟合”显示可拖动区间及有效点数，复用现有拟合范围；仅按 X 选区，矩形框选和叠加图选点仍待后续。临时选点不保存到工程。

工程打开仍同步；后台保存不代表后台打开已经完成。按用户最新要求，体验测试主要由用户完成，开发端保留必要的数据保护及启动检查，本版不声称所有需求已验收。

## 0.2.0-alpha.4：常见拟合与结果

单曲线右侧“拟合”页现在可直接选择线性、二次多项式、Gaussian、Lorentzian、指数衰减。选择后自动调用 lmfit 估计初值；现有参数行可编辑初值、上下界和“固定”，设置 X 拟合范围后可重新估计，再点击“执行拟合”。切换“自定义公式”继续使用 Tailor 原有表达式功能。预设公式中的 x 始终表示当前源 X 列，与实际列名无关。

Gaussian/Lorentzian 含可拟合常数基线；amplitude 表示峰面积，sigma 分别为标准差/半高半宽。结果下方显示原生 lmfit 派生的 FWHM、峰高及列单位。参数标准误沿用 lmfit，FWHM/峰高暂不提供传播标准误。指数预设使用正 decay 衰减模型。

结果区可“复制结果”、导出“参数 CSV”或“残差 CSV”。导出在后台完成，可取消；残差为原始 Y 减拟合 Y，并附 1 起算的真实源行号，只导出当前有效拟合区间中的有效数据。数据或参数改变后必须重新拟合，不能导出过期结果。

未关联 Y 误差时执行普通未加权拟合；关联时要求每个参与拟合的 Y 误差严格为正，权重为 1/σ。X 误差仍仅用于显示，不参与此次最小二乘权重。零误差不能作为有效加权输入。

工程保存预设 ID、现有参数与区间，旧工程继续按表达式读取。“帮助 → 打开合成示例”直接显示右侧拟合页。仍然复用 Tailor 的表达式、参数控件和 lmfit 拟合执行流程，没有另写数学拟合器。本轮尚未后台化拟合；50 万点拟合性能、多峰/Voigt/置信带和外部插件发现仍待后续。

## 0.2.0-alpha.5：统一四页与基础处理

保持原生字体和配色，移除左侧项目栏，通过顶部工作表/图形标签切换。点击右侧各页的小三角标题展开/收起；多个功能可以同时展开并滚动，未展开入口固定在底部。

- 图形：坐标轴与裁切、曲线与字体、选择数据点、图例。填写 X/Y 四个上下限后，裁切删除范围外的源表整行（含无效坐标），同表其他图形随之改变；可撤销，不写入原始 CSV。原拖动 X 区间入口已移除，拟合范围改用数值设置。轴名不再自动附加单位；需要单位时可写入轴名。
- 拟合：模型与初值、参数与执行、拟合范围、拟合结果。继续复用 Tailor/lmfit。数据和拟合曲线右上角显示图例，可改数据图例名称。
- 处理：移动平均、Savitzky–Golay（二次，要求递增等间距 X、奇数窗口）、每 N 点平均（保留不足 N 点的末组）、减常数/两端各10%均值直线基线、同表参考列乘系数后相减、最大绝对值/0–1归一化。可按全部数据或当前坐标范围处理；预览为橙色曲线，生成结果建立独立工作表。原数据保持，误差未传播。参考相减按同行对应，不插值。取消在库计算返回后丢弃结果。
- 导出：PNG/SVG/PDF、拟合参数/残差 CSV、源工作表 CSV。临时处理预览不作为正式导出曲线；需要导出处理结果时从独立结果表绘图。

叠加图的拟合/处理页先选择源曲线再打开其设置，暂不批量处理全部曲线。图内拟合结果表、导出 DPI/尺寸、高级基线、误差传播和外部插件加载留待后续。50 万点拟合仍同步，真实大表长流程仍待用户试用，不能视为阶段验收通过。

## 0.2.0-alpha.6：后台拟合

在“拟合 → 参数与执行”点击执行，原按钮变为“取消拟合”；状态栏显示评估次数。计算期间可浏览图表；如果修改数据、参数或其他工程设置，则丢弃旧快照结果，需重新拟合。取消通过lmfit迭代回调生效，当前一次计算结束后响应，不能承诺任意函数瞬时停止。为保护数据，后台拟合完成/取消前不能关闭或替换工程。

结果、权重、线宽、参数CSV仍用原有流程，界面样式保持。工程打开及恢复旧拟合仍同步；自动估计初值也未后台化。此项替代alpha.5说明中的手动拟合同步限制，不代表所有大数据场景均已验证。

## alpha.6 本轮界面与基础操作修订（以本节为准）

顶部 ▦ 表示工作表，⌁ 表示图形。左端箭头撤销/重做当前源表的数据、列元数据、裁切和已记录的图形样式/坐标修改；不是页面前后导航，也不覆盖拟合任务和创建/关闭标签。空白Sheet可直接关闭，非空或有关联图形会说明影响再关闭。

工作表表头固定两行编辑区：角色下拉（X/Y/X误差/Y误差/无）和列名。它们是元数据，数据行1仍是原始第一条数值。导出CSV使用名称为表头，不将角色作为数值行。

功能现在按原位置折叠和滚动，不停靠底部。图形页顺序：曲线与字体、图例、坐标轴与裁切、选择数据点。选择折线禁用点大小，选择散点禁用线型/线宽，线点同时开放。点击图中的横/纵轴刻度、轴名或图例，或在文字对象下拉中选择，字体与字号仅作用于该对象。此设置随工程保存，并用于SVG/PDF/PNG导出。选点默认开启，定位工作表仍由按钮手动触发。

坐标范围填写过程中不再逐字重绘，点击“应用坐标范围”统一生效。裁切只使用已填边界：例如只填X最小值5，删除X<5的整行，再把保留行的X减5；未填Y不会按Y过滤。归零只支持普通X列，计算X列需先复制；顶栏可一次撤销裁切/归零，原CSV不改。

拟合页依次选择模型、设置范围、编辑初值/下界/上界/固定并执行、查看结果；取消仍使用原执行按钮。处理页紧凑布局，取消按钮仅在计算期间显示。Origin .opj/.opju工程不支持，继续使用CSV、SVG/PDF交换数据和图形。
